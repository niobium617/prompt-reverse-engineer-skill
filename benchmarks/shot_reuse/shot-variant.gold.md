# 金标：镜头复用 → 变体模式（单镜，机位轴）

## 输入

`tools/fixtures/semantic_shot_variant.json`：6 秒雨夜街角基准镜的 3 秒变体；`reuse_mode=variant`，`variant_of=雨夜街角基准镜 1`，`variant_axis=camera_angle`，Delta 只写「机位由平拍改为仰拍」；镜头卡相机角为 `仰拍`；另含人物 / 场景 / 风格三组连续性资料。

## 结构层金标（自动校验）

- 复用计划模式为 `variant`；`variant_of` 与 `variant_axis` 原样输出。
- `manifest.changed` 长度 1（只改机位），保留 4、必须联动 2、无法保证 1。
- `profile_notes` 三组各 1 条；Prompt 正文不得出现 `左眉疤痕`（资料只进审查参考）。
- 镜头数 1；每镜 4 条 Prompt；审查清单 9 项。
- 不得出现 `{`、`}`、`uncertainty`。

## 语义层金标（人工 / Agent 评分）

### 必须命中

1. **单轴变体**：只沿 `camera_angle` 从平拍改仰拍；景别、动作、时长、天气、服装均与基准一致。
2. **基准可追溯**：`variant_of` 与 `variant_axis` 能让读者找到基准镜；Markdown 说明「同一基准镜头的变体之一」，不冒充独立镜头。
3. **联动可验收**：仰拍带来的天花板占比、霓虹招牌透视、湿地面倒影压缩三项能对应到镜头卡光影/构图/色彩。
4. **资料只作审查**：人物、场景、风格资料不进入 Prompt 正文；需要时由 Agent 显式引用。
5. **平台语法**：四模型各自独立可粘贴，变体说明不混入正文。

### 允许的合理改写

- Delta 可写成「平拍→仰拍，机位降低约 30cm」，但不得新增第二条变体轴。
- 联动项可拆成四条，但不得删掉倒影透视。

### 不允许

- 同一文件内改两个轴（如同时改景别与机位）。
- 把连续性资料整段塞进每个模型的 Prompt。
- 把 `variant_of` 省略或写成空串。
- Prompt 出现空标签、模板变量残留或 `unknown:` 内容。

## 评分锚点（0–2 / 维）

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 单轴变体 | 多轴改动 | 夹带轻微改动 | 只改机位 |
| 基准可追溯 | 无基准 | 基准含糊 | variant_of / axis 齐全 |
| 联动一致性 | 未提联动 | 提了但不可验收 | 三项落到镜头卡 |
| 资料边界 | 资料进正文 | 边界含糊 | 只进审查参考 |
| 平台语法 | 语法破坏 | 基本可用 | 四模型正确且独立可粘贴 |
