# 金标：镜头复用 → 局部修改（两镜，四模型）

## 输入

`tools/fixtures/semantic_shot_reuse.json`：6 秒雨夜街角两镜；`reuse_mode=local_edit`，基准为男性撑黑伞，Delta 为「主体替换为女性、穿白色西装」与「黑伞替换为透明伞」，Preserve 覆盖构图、运镜、动作时序、雨夜氛围，另含 `forbidden_changes`、`dependent_updates`、`uncontrollable` 与镜头卡扩展字段。

## 结构层金标（自动校验）

- 复用计划模式为 `local_edit`；`manifest.changed` 首项为「主体由男性替换为女性，穿白色西装」。
- `manifest` 四栏长度：已修改 2、保留 4、必须联动 3、无法保证 2，与输入字段一一对应。
- 镜头数 2；每镜 4 条 Prompt；审查清单至少 9 项，第 7–9 项依次为 `reuse_contract` / `reuse_conflict` / `continuity_state`。
- 不得出现 `{`、`}`、`uncertainty`。

## 语义层金标（人工 / Agent 评分）

### 必须命中

1. **Delta 最小**：只写主体性别/服装与伞的替换；不得夹带「换构图」「换运镜」「改时间」等未授权改动。
2. **Preserve 明确**：构图（人物右三分之一、招牌留白）、运镜（固定机位 + 轻微手持）、动作时序（站立回望 3 秒后转身）、雨夜氛围四项齐全。
3. **联动项可验收**：白色西装的湿润褶皱与高光、湿地面白色倒影、透明伞透光对面部补光，三项均能对应到镜头卡的光影/色彩/锚点。
4. **能力边界诚实**：`uncontrollable` 只写「构图比例锁定」「透明伞与黑伞透光差异」等模型能力问题，不写「懒得保证」。
5. **平台语法不变**：四模型仍按各自 `shot_style` 渲染两镜；复用计划字段不进入 Prompt 正文。

### 允许的合理改写

- Delta 可拆得更细（如「女性」与「白色西装」分两条），但语义必须等价。
- 联动项可补充「手部与伞柄接触点」，但不得删掉阴影与倒影。

### 不允许

- 把 Delta 写成整段新 Prompt，覆盖基准。
- 把 Preserve 与 Delta 冲突项同时保留却不给复核提示。
- 未声明 `reuse_mode` 却输出复用计划，或声明后遗漏四栏。
- Prompt 出现空标签、模板变量残留或 `unknown:` 内容。

## 评分锚点（0–2 / 维）

| 维度 | 0 | 1 | 2 |
