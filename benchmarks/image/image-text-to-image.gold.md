# 金标：图片逆向 → 文生图（Midjourney / GPT Image）

## 输入

`tools/fixtures/semantic_image.json`：一张赛博朋克雨夜城市海报的分析结果，含主体、场景、构图、光影、色彩、风格、镜头参数、画质词、负向词、目标风格、画内文字 `APS 2077` 与两条参考图说明。

## 结构层金标（自动校验）

- 模型集合：`midjourney`、`gpt_image`。
- 输出用途：MJ 为 `positive` / `negative` / `style_transfer`；GPT Image 为 `prompt` / `params`。
- 共 5 条 Prompt，无跳过模型。
- MJ 正向含 `/imagine prompt:`、画内文字 `APS 2077`、`--ar 16:9`；负向含 `--no blurry`。
- GPT prompt 含 `Subject:`、`Text in image: APS 2077`、`References:`；params 含 `quality: high` 与画幅。
- 所有正文不得出现 `{`、`}`、`uncertainty` 或空标签造成的 `。。`。

## 语义层金标（人工 / Agent 评分）

### 必须命中

1. **七类信息齐全**：主体（天际线、发光广告牌、撑透明伞行人）、场景（雨夜霓虹街道、潮湿反光地面、2077 年）、构图（低角度仰拍、全景、三分法、建筑群居中偏右）、光影（霓虹侧光与轮廓光、高对比、蓝调时刻）、色彩（深蓝紫主色、霓虹橙与青色点缀）、风格（赛博朋克电影感）、镜头（24mm、f/2.8、深景深）。
2. **画内文字逐字准确**：只保留 `APS 2077`，不翻译、不扩写、不添加标语。
3. **负向职责分离**：MJ 负向词只出现在 `--no` 段；GPT 约束段只出现一次，且明确「不额外添加文字、Logo、水印」。
4. **风格迁移是独立支路**：`style_transfer` 只替换目标风格（吉卜力动画风格），其余画面事实保持不变。
5. **参数只进 params 块**：版本、画幅等平台参数不混入画面正文。

### 允许的合理改写

- 中英文标点差异；MJ 质量词与 GPT `Quality` 段顺序不同。
- 参考图说明可放在 `References:` 或 MJ 正文末尾，但不得改变参考图职责。

### 不允许

- 把「赛博朋克」扩写成未出现的具体品牌、地标或人物。
- 把推断的相机参数写成 EXIF 已观测事实。
- 在 GPT 正文中重复负向词导致语义冲突。
- 出现未填字段残留的 `{字段名}` 或连续中文句号。
