# 金标：图片逆向 → 单帧镜头反推（六模型 shots）

## 输入

`tools/fixtures/semantic_shot_reverse_image.json`：一张雨夜街头女子特写，含 EXIF 85mm / f/1.8、observed / inferred / unknown 三类证据、镜头卡字段与负向词。

## 结构层金标（自动校验）

- 镜头数 1，镜头卡：`shot_size = 特写`、`camera_angle = 平拍`、`duration_s = 3`。
- 模型集合：`midjourney`、`stable_diffusion`、`flux2`、`gpt_image`、`muse_image`、`nano_banana`。
- 每镜 6 条 Prompt，审查清单至少 6 项，跳过 0 个模型。
- 不得出现 `{`、`}`、`uncertainty`。

## 语义层金标（人工 / Agent 评分）

### 必须命中

1. **证据分层**：85mm、f/1.8 标为 observed（EXIF）；浅景深、上方招牌为主光标为 inferred；无法判断的具体地点标 unknown，不进入正文断言。
2. **镜头事实一致**：六模型共享同一组景别、机位、焦距、焦点、主体动作、环境、光影、色彩、声音、衔接；平台改写不得改变「特写 / 平拍 / 固定 / 3 秒」。
3. **单帧不编运镜**：不能把静态照片写成推、拉、摇、移的连续运动；`camera_move` 只能是「固定」或明确标注为建议。
4. **平台语法**：MJ 带 `--ar 16:9` 与负向词；SD / Flux 用结构化正向 + Negative prompt；GPT / Nano / Muse 用自然语言约束；均不得残留占位符。
5. **审查清单**：覆盖主体、构图、光影、文字、参考图、置信度六类，且不把 unknown 当 pass 的理由。

### 允许的合理改写

- 各平台对「85mm 中长焦」的表述不同（如 `85mm lens` / `中长焦`），只要焦距与景深关系不变。
- 声音设计可从画面推断（雨声、远处车流），但需保持低置信度语气。

### 不允许

- 把单帧扩写成多镜头分镜。
- 把 inferred 的「浅景深」写成 EXIF 直接记录。
- 六个模型给出互相冲突的景别或机位。
- 出现空标签或未替换的模板变量。

## 评分锚点（0–2 / 维）

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 事实与推断分离 | 推断当事实 | 部分标注 | observed/inferred/unknown 清楚 |
| 需求覆盖 | 缺镜头核心字段 | 缺一到两项 | 六模型共享完整镜头卡 |

| 一致性与可执行 | 单帧编运镜/互相冲突 | 局部不一致 | 六模型事实一致 |
| 安全与边界 | 伪造 EXIF/地点 | 边界模糊 | 明确 unknown 不外推 |
