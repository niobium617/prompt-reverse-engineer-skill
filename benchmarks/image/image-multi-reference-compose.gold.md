# 金标：图片逆向 → 三图参考合成（Muse Image compose）

## 输入

`tools/fixtures/semantic_muse_image.json`：三张参考图分别提供机器人身份、站姿与工业背景，要求合成一张雨夜工业场景图。含主体位置与比例、九类空间关系、构图、光影、色彩、材质、参考图用途与禁止迁移项。

## 结构层金标（自动校验）

- 模型集合仅 `muse_image`，用途仅 `compose`。
- 输出 1 条 Prompt，无跳过模型。
- 正文必须包含 `Compose a new image`、三种参考角色 `identity_reference` / `pose_reference` / `background_reference`、`禁止迁移`、`Aspect ratio: 16:9`。
- 不得出现 `{`、`}`、`uncertainty` 或 `。。`。

## 语义层金标（人工 / Agent 评分）

### 必须命中

1. **参考职责三分**：
   - 图1 只取机器人头部轮廓、胸口核心、装甲比例与配色；禁止迁移原图背景与光照。
   - 图2 只取站姿、右手持剑角度、左肩朝向；禁止迁移人物服装与面部。
   - 图3 只取高炉、管道、蒸汽层次；禁止迁移原图人物与前景平台。
2. **空间关系逐条落地**：position、direction、distance、interaction、occlusion、containment、alignment、scale、depth、attachment 至少覆盖八项，且与主体位置「中央偏左、前景平台」一致。
3. **统一性约束**：明确要求统一透视、光向、色温、材质，禁止直接拼贴或粘贴参考图。
4. **比例与构图**：机器人约占画面高度三分之二，压在左三分线，长剑与右侧蒸汽形成对角引导线。
5. **光影色彩**：冷蓝主光自左上，右侧蒸汽暖橙逆光，湿金属条状高光；深蓝青灰主色，蓝核心与橙逆光为强调色。

### 允许的合理改写

- 参考角色英文标签可换成同义中文，但三类职责不得合并。
- 空间关系顺序可调整，不得遗漏遮挡、包含、比例三类。

### 不允许

- 让任一张参考图同时承担身份、姿态与背景三种职责。
- 把三张图直接描述成拼贴结果。
- 引入参考图中不存在的角色、道具或文字。
- 把推测的空间距离写成精确测量值。

## 评分锚点（0–2 / 维）

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 事实与推断分离 | 把推测写成测量值 | 有模糊表述 | 参考职责与可见事实清楚 |
| 需求覆盖 | 缺参考职责或空间关系 | 缺一到两项 | 三图职责 + 八项空间关系齐全 |
| 平台语法 | 参考段格式错误 | 基本正确但边界不全 | 角色/用途/保留/禁止四段完整 |
| 一致性与可执行 | 拼贴式描述或光影冲突 | 局部不一致 | 透视、光向、色温统一 |
| 安全与边界 | 迁移禁止项 | 边界模糊 | 明确禁止迁移与直接粘贴 |
