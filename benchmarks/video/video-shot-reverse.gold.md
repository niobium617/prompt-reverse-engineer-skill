# 金标：视频逆向 → 三镜实拍反推（四模型 shots）

## 输入

`tools/fixtures/semantic_shot_reverse.json`：10 秒实拍片段，三镜为远景固定 3 秒、中景横移 4 秒、特写固定 3 秒；含镜头卡、风格、画幅、总时长、色彩脚本、声音计划、连续性说明、负向词与 observed / inferred / unknown 证据。

## 结构层金标（自动校验）

- 镜头数 3；`shot_size` 依次为远景、中景、特写；第三镜 `duration_s = 3`。
- 模型集合：`sora2`、`runway`、`veo3`、`seedance`。
- 每镜 4 条 Prompt，审查清单至少 6 项，跳过 0 个模型。
- 不得出现 `{`、`}`、`uncertainty`。

## 语义层金标（人工 / Agent 评分）

### 必须命中

1. **逐镜十要素**：景别、机位、运镜、时长、主体动作、环境、光影、色彩、声音、衔接均落到每镜；不得只写第一镜。
2. **连续性**：黑风衣、透明伞贯穿三镜；霓虹位置不跳；第三镜「渐暗」与第二镜亮度衔接自然。
3. **证据分层**：`observed`（画面可见反射、雨、伞）与 `inferred`（拍摄时间、光源方向）分开；`unknown`（具体地点、镜头型号）不写成确定事实。
4. **平台语法**：Sora / Runway / Veo 保留逐镜格式与参数段；Seedance 用参考/镜头语法；负向词单独成段。
5. **审查清单**：覆盖镜头卡完整性、连续性、负向词、参考角色与置信度。

### 允许的合理改写

- 「固定」可写作 `static` / `固定机位`。
- 声音计划可压缩，但雨声、车流、伞面滴水三类不得全删。

### 不允许

- 把三镜合并成一段概述。
- 改变景别顺序或时长。
- 把 inferred 的光源方向写成 observed。
- 负向词进入正向描述。
- 出现空标签或模板变量残留。
