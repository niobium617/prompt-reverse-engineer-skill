# 金标：视频逆向 → 三镜故事板（六模型）

## 输入

`tools/fixtures/semantic_video.json`：10 秒雨夜霓虹故事板，三镜为远景推进 3 秒、中景横移跟拍 4 秒、特写拉远 3 秒，含人物、摄影、灯光、色彩、氛围、声音、旁白与两条参考图说明。

## 结构层金标（自动校验）

- 模型集合：`sora2`、`runway`、`veo3`、`kling`、`hailuo`、`vidu`。
- 用途：Sora / Runway 为 `storyboard` + `replicate` + `params`；Veo 为 `storyboard` + `negative` + `params`；可灵 / 海螺 / Vidu 为 `storyboard` + `params`。
- 共 15 条 Prompt，无跳过模型。
- 海螺正文含 `integrated_multimodal_description:`、`overall_soundscape:`、`non_diegetic_music: 无额外配乐`。
- 可灵 / 海螺 / Vidu 的 params 块含各自模型 ID，且 `generate_audio: true`。
- 正文不得出现 `{`、`}`、`uncertainty` 或 `。。`。

## 语义层金标（人工 / Agent 评分）

### 必须命中

1. **三镜不漂移**：
   - 镜头1 远景、慢速推进、3 秒，女子撑伞从深处走近；
   - 镜头2 中景、横向跟拍、4 秒，穿行人群与灯牌之间；
   - 镜头3 特写、缓慢拉远、3 秒，抬头、瞳孔倒映全息广告牌、画面渐暗，台词保留。
2. **跨镜连续性**：黑色风衣、透明伞、雨夜、霓虹位置不跳变；人物年龄与神情一致。
3. **平台语法**：
   - Sora / Runway 保留逐镜格式与摄影/灯光/色彩/声音段；
   - Veo 的负向词单独成段；
   - 可灵用 `【整体设定】【主体与动作】【光影】` 等标签组织；
   - 海螺使用官方四段结构，`non_diegetic_music` 明确写「无额外配乐」而不是虚构配乐；
   - Vidu 用「主体 / 动作与情节 / 场景 / 参考主体」顺序。
4. **参数隔离**：时长、画幅、分辨率、音频开关、模型 ID 只出现在 `params`，不进入画面正文。
5. **参考图职责**：两条参考图说明若保留，只能描述人物造型与街道氛围，不得扩写成新角色或新场景。

### 允许的合理改写

- 平台标签中英混用；镜头描述顺序微调。
- 声音段可按平台拆成 `音频` / `overall_soundscape` / `声音`。

### 不允许

- 改变镜头数量、景别或时长。
- 把「无额外配乐」写成具体配乐风格。
- 把可灵 / Vidu 的 Skill 标签写成官方固定模板。
- 负向词进入正向正文，或参数混入故事描述。
- 出现空标签或未替换变量。

## 评分锚点（0–2 / 维）

| 维度 | 0 | 1 | 2 |
| --- | --- | --- | --- |
| 事实与推断分离 | 虚构镜头/配乐 | 局部越界 | 事实与设计边界清楚 |
| 需求覆盖 | 缺镜头或声音 | 缺一到两项 | 三镜 + 声音 + 参考齐全 |
| 平台语法 | 标签错乱 | 基本正确 | 六平台语法正确 |
| 一致性与可执行 | 镜头漂移/参数混入 | 局部不一致 | 三镜一致、参数隔离 |
| 安全与边界 | 冒充官方模板 | 边界模糊 | 明确标注 Skill 设计 |
