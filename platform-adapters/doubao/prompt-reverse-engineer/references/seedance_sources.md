## 边界

- 模型标识、任务场景、素材角色枚举、参数取值、时长与格式限制、互斥规则、真人人脸限制：以火山方舟官方文档为准。
- 六种任务模式、视频逆向维度、扁平字段契约、六段式编译、P0–P3、六维评分、Seedance 审查清单：本 Skill 的设计建议，不是字节官方 Prompt 格式。
- 官方没有规定“Seedance 标准 Prompt 格式”。本 Skill 输出可直接粘贴的自然语言分镜指令，不把内部 JSON 直接发给模型。

## 维护

- 新增官方资料时更新本表与 `seedance_rules.md` §0、§14。
- 模型能力变化时先改 `seedance_rules.md` 与 `assets/templates/seedance.json`，不要改 `video_rules.md` 中其他模型的模板。
- API 参数变化只影响本文档与规则文件 §9、§12，不影响 Prompt 模板。
- 若官方新增任务场景或素材 role，先确认是否与现有六模式、三角色冲突，再决定扩展字段还是新增 kind。
