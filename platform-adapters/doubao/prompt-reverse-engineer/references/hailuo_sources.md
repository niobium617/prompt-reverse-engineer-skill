## 边界

- 模型标识、模式支持、时长与分辨率档位、音频参数、提示词长度上限：以 MiniMax 官方文档与控制台为准。
- 四段结构与两个声音字段来自官方提示词指南；模板中的中文标签是本 Skill 的映射写法，不是官方逐字模板。
- 本 Skill 没有独立配乐字段：`non_diegetic_music` 固定写「无额外配乐」，画外音另起一行；用户提供的音乐描述应写入 `audio`。这是 Skill 的字段取舍，不是官方要求。
- `4-15 秒、768P/1080P` 为公开资料常见值，实际档位以控制台为准。
- 扁平字段契约、P0–P3、六维评分、审查清单：本 Skill 的设计建议。
