## 边界

- 模型标识、分辨率/画幅档位、水印参数、参考图数量、文字渲染能力：以即梦控制台与火山方舟官方文档为准。
- `模型 ID = seedream-5.0、分辨率 2K` 是模板中的 Skill 侧快照，不是已核对的官方 API 值；接入前必须按账号控制台替换。
- 「主体 + 行为 + 环境 + 材质 + 光影 + 构图 + 风格」顺序、扁平字段契约、P0–P3、六维评分、审查清单：本 Skill 的设计建议，不是官方固定 Prompt 模板。
- 文字渲染要求逐字准确是本 Skill 的约束写法；官方能力上限（字数、语言、排版复杂度）以官方说明为准。
