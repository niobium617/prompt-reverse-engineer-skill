## 边界

- 模型标识、模式支持、时长与分辨率档位、参考素材数量、提示词长度上限、音频参数：以可灵官方文档与控制台为准。
- 本索引未逐页核对正文；`kling.json` 中 `3-30 秒、720p/1080p` 等为公开资料常见值，若与账号控制台不一致，以控制台为准并更新模板 `notes`。
- 「素材职责 / 整体设定 / 主体与动作 / 镜头 / 环境光影 / 分段事件 / 声音」七段结构、扁平字段契约、P0–P3、六维评分、审查清单：本 Skill 的设计建议，不是可灵官方规定的固定 Prompt 模板。
- 官方不主张堆叠负向词；模板只渲染用户明确给出的 `negative_words`，不自动生成负向清单。
