# 统一 Prompt → ComfyUI 映射规则

> 平台：ComfyUI ｜ 核验日期：2026-11-17 ｜ 能力等级：L2
> 结构事实来源见 [platform_rules.md](platform_rules.md) 与 [sources.md](sources.md)；节点类名一律**需人工确认**。

## 1. 总原则

ComfyUI 没有「一个 Prompt 输入框」。统一 Prompt 必须拆成**文本、参数、素材**三类，分别落到不同节点：

```
统一 Prompt
├── 正向语义文本  → 文本编码节点（正向）
├── 负向语义文本  → 文本编码节点（负向）或采样节点负向输入
├── 参数（画幅/步数/CFG/种子/采样器） → 对应节点 inputs
└── 素材（参考图/蒙版/控制图） → 加载与预处理节点，占工作流连线
```

**不要**把 `--ar 16:9`、`--v 8.2`、`seed: 123` 之类的参数写进正向文本；ComfyUI 不解析这些标记。

## 2. 文本写法

### 2.1 正向文本

- 用自然语言或逗号短语均可，取决于目标模型的训练习惯；本 Skill 默认输出自然语言完整句，用户可再压缩为关键词。
- 一段工作流若有多个正向文本节点（如分阶段重绘），按阶段拆段，不要把所有描述塞进第一个节点。
- 主体、场景、光影、风格、镜头、画质保持原有顺序；这是 ComfyUI 常见的提示词阅读顺序，但**不是平台强制的语法**。
- 画内文字用引号标出，并说明字体/位置；ComfyUI 本身不保证文字渲染，需目标模型支持。

### 2.2 负向文本

- 单独成段，放入负向编码节点；不要用「不要……」「避免……」写进正向文本。
- 负向词按三类组织：质量缺陷、解剖/结构错误、内容排除。
- 若目标工作流没有负向输入（如部分蒸馏模型），明确写「该工作流不支持独立负向」，不要硬塞。

### 2.3 多镜头

ComfyUI 单次工作流通常生成一个镜头或一个批次的同构画面。多镜头应：

1. 每个镜头一份独立正向文本；
2. 共用同一套角色/场景锚点描述；
3. 在说明中给出镜头顺序与衔接方式；
4. 不声称一次工作流自动完成多镜头叙事（除非用户已有对应工作流，且需人工确认）。

## 3. 参数映射

| 统一字段 | 建议落点 | 置信度 | 写法 |
|---|---|---|---|
| `aspect_ratio` | 空 latent / 图像尺寸节点 | 需人工确认 | `16:9` 需换算为宽高像素 |
| `resolution` | 同上 | 需人工确认 | 给宽×高，不写「4K」等营销词 |
| `steps` | 采样器节点 | 需人工确认 | 整数 |
| `cfg` | 采样器节点 | 需人工确认 | 浮点 |
| `seed` | 采样器节点 | 需人工确认 | 整数；固定种子才可复现 |
| `sampler` | 采样器节点 | 需人工确认 | 写节点下拉项名称，不臆造 |
| `scheduler` | 采样器节点 | 需人工确认 | 同上 |
| `denoise` | 图生图/重绘工作流 | 需人工确认 | 0–1 |
| `lora_weight` | LoRA 加载节点 | 需人工确认 | 模型名 + 权重 |
| `controlnet_strength` | 控制网应用节点 | 需人工确认 | 控制图 + 强度 |

参数只进入「参数表」，不进入 Prompt 正文；表中每行都带落点与置信度。

## 4. 素材映射

| 统一素材角色 | ComfyUI 落点 | 置信度 |
|---|---|---|
| 编辑目标 / 底图 | 图像加载节点 → 图生图或重绘链路 | 需人工确认 |
| 人物/主体参考 | 图像加载 + 参考类节点（IPAdapter 等，属自定义节点） | 未验证 |
| 姿态/构图参考 | 图像加载 + 预处理 + 控制网节点 | 需人工确认 |
| 风格参考 | 图像加载 + 风格迁移/参考类节点 | 未验证 |
| 蒙版 | 蒙版加载/绘制节点 → 局部重绘链路 | 需人工确认 |

参考图在 ComfyUI 中不是「Prompt 的一部分」，而是工作流输入。回答时必须同时说明：

- 图片放到哪个加载节点；
- 接到哪类预处理/控制节点；
- 需要哪些自定义节点与模型；
- 缺依赖时如何降级（只给文本 Prompt，不给虚假连线）。

## 5. 输出模板

回答「这个效果在 ComfyUI 里怎么搭」时，固定给出：

1. **映射结果**：正向文本、负向文本、参数表、素材表；
2. **节点/功能清单**：按数据流向排序，标出关键输入输出；
3. **依赖清单**：模型、LoRA、ControlNet、自定义节点；缺失项标 `unknown`；
4. **不兼容项**：无法在 ComfyUI 复现的部分及原因；
5. **降级方案**：缺节点/缺模型/无工作流时怎么退；
6. **置信度标记**：已验证 / 未验证 / 需人工确认（逐条）。

## 6. 示例（片段）

统一 Prompt（图片）：

> 雨夜霓虹街道，女性侦探撑黑伞站在便利店门口，低机位广角，青蓝主色，红色招牌反光，电影感，35mm。

ComfyUI 映射（示意，类名需人工确认）：

| 项 | 内容 |
|---|---|
| 正向文本 | 雨夜霓虹街道，女性侦探撑黑伞站在便利店门口，低机位广角，青蓝主色，红色招牌反光，电影感，35mm |
| 负向文本 | 模糊，低清晰度，畸形手指，多余肢体，水印，文字 |
| 参数 | 宽高按 16:9 换算；步数/CFG/采样器/种子待用户工作流确认 |
| 节点（示意） | 模型加载 → 正向/负向文本编码 → 空 latent → 采样器 → VAE 解码 → 保存图像 |
| 依赖 | 目标 checkpoint；无额外自定义节点（若使用参考图则另加加载与控制节点） |
| 置信度 | 文本与参数映射：需人工确认；格式与导出方式：已验证（官方文档） |

> 该示例只说明写法，**不是可导入的工作流**，也不保证在任意 ComfyUI 版本中可直接搭建。
