# LibTV 平台规则

> 核验日期：2026-11-17 ｜ 状态：`verified` ｜ 本 Skill 能力等级：L1
> 官方来源与未核验边界见 [sources.md](sources.md)。LibTV 由 LiblibAI 提供，定位为 AI 视频创作平台。

## 1. 平台定位（官方已确认）

LibTV 提供两类入口：

- **LibTV 画布**：在画布中组织创作；
- **LibTV Agent（BETA）**：用 Agent 辅助创作；
- 另有 **LibTV 3D-BOX**。

官方首页列出的创作能力：**视频生成、图片生成、音频生成、剧本生成、智能剪辑**；导航含「项目 / 资产 / 插件 / 创作」。

官方 AI 视频落地页进一步说明：

- 「一句话剧本复刻爆款成片」「一万字剧本，直出 80 集爆款短剧」；
- **6 大场景模板**（短剧、漫剧、影视、自媒体、TVC 广告、游戏）；
- **导入剧本**、**原创剧本与改编**；
- **TV Director** 辅助分镜语言与导演风格；
- 剧本设定项：核心看点、时代背景、目标受众、角色设定；
- 支持多个视频/图片模型（首页列出 Wan 3.0、Kling 4.0、SD2 Mini&Fast、SD 2.5 Flash、Seedream 5.5、Seedance 2.5；落地页另见 MiniMax H3、Kling 4.0 原生 4K）。

官方插件页说明：LibTV Plugin 可让 Agent「自动化生成视频或图像」，并列出 OpenAI、Claude、Claude Code、OpenClaw、Hermes、CodeBuddy 等宿主；安装方式为向 Agent 发送 `codex plugin marketplace add https://github.com/liblib-ai/marketplace.git --ref main`、`codex plugin add libtv@libtv`，新建任务后完成 **LibTV 账户授权**。

## 2. 能力边界（重要）

官方公开页面讲的是**产品功能与创作流程**，没有公开：

- 画布内部的节点类型、连线格式、节点参数；
- 工作流/项目文件的导入导出格式；
- 可供第三方调用的公开 REST API 与鉴权细节；
- 「Agent 自动生成」的具体调用链、配额与计费。

因此本目录：

- `workflow_formats` 为空；
- `import_export` 与 `api.cloud` 标 `unknown`；
- 节点级映射只登记到「功能/步骤」层级，不编造节点名与端口；
- **不承诺**任何 Agent 流程可被本 Skill 自动执行。

> 插件页的「自动化生成」是 **LibTV 平台 + 其 Plugin 的原生能力**，不是本 Skill 的能力。本 Skill 不安装插件、不授权账号、不调用生成接口。

## 3. 推荐创作流程映射

统一需求进入 LibTV 时，按官方产品流程组织：

```
剧本 / 创意
  → 剧本生成或导入剧本
  → 角色设定 + 核心看点 / 时代背景 / 目标受众
  → 分镜（镜头列表 / 场景模板）
  → 逐镜图片或视频生成
  → 音频生成 / 智能剪辑
  → 项目 / 资产中管理成片与素材
```

其中「分镜」的字段结构、每个镜头能填哪些参数，官方未公开；本 Skill 只给**分镜内容与逐镜 Prompt**，具体填入位置标「需人工确认」。

## 4. 本 Skill 的使用规则

### 4.1 Prompt 落点

- **剧本层**：题材、一句话梗概、角色、世界观、核心冲突；
- **角色层**：外形、服装、年龄、气质、跨镜一致性约束；
- **分镜层**：镜号、景别、运镜、时长意图、画面内容、台词/旁白；
- **逐镜生成层**：每镜一条图片或视频 Prompt，写明主体、动作、场景、光影、风格；
- **音频层**：配音、音效、配乐意图（官方有音频生成能力，但接口/参数未核验）；
- **剪辑层**：镜头顺序、节奏、转场意图（官方有智能剪辑，细节未核验）。

### 4.2 参数与选项

| 统一字段 | LibTV 落点 | 置信度 |
|---|---|---|
| 模型选择 | 生成界面的模型选项（Wan / Kling / Seedance 等） | 已验证（模型存在）／可用性需人工确认 |
| 画幅 / 分辨率 / 时长 | 生成界面选项 | 需人工确认 |
| 场景模板 | 6 大场景模板 | 已验证（模板类别）／具体选项需人工确认 |
| 角色一致性 | 角色设定 / 资产 | 需人工确认（实现方式未公开） |
| 分镜字段 | 分镜/剧本界面 | 未验证（官方未公开字段） |
| 音频/配乐参数 | 音频生成界面 | 未验证 |
| API 参数 | 未公开 | unknown |

### 4.3 输出要求

回答「LibTV 的分镜/角色流程怎么对应」时，固定给出：

1. **创作步骤映射**：剧本 → 角色 → 分镜 → 逐镜生成 → 音频/剪辑；
2. **逐镜 Prompt**：每镜可独立粘贴；
3. **角色一致性做法**：文字锚点 + 参考资产建议（不承诺平台自动锁定）；
4. **不兼容项**：无法确认的节点/字段/API；
5. **降级方案**：平台字段不可见时，只给剧本/分镜/逐镜 Prompt，由用户手动填入；
6. **置信度标记**：已验证 / 未验证 / 需人工确认。

## 5. 不兼容与降级

| 情况 | 处理 |
|---|---|
| 用户要「自动在 LibTV 里跑完整条片子」 | 明确拒绝：本 Skill 不做 L4；只给人工操作步骤与 Prompt |
| 用户要 LibTV 项目/工作流文件 | 官方未公开格式；无法提供，改为步骤说明 |
| 用户要公开 API 调用方式 | 未核验到公开 REST API；不提供臆造端点，建议走官方 Plugin/文档 |
| 用户要精确分镜字段或节点参数 | 标「需人工确认」，以账号内界面为准 |
| 安装态读不到 `platforms/` | 只输出通用 Prompt，并说明未加载 LibTV 平台资料 |

## 6. 安全边界

- 不安装 LibTV Plugin、不完成账号授权、不读取账号数据；
- 不调用任何生成接口，不索取 API Key / Cookie / 登录凭证；
- 不把落地页的营销表述（如「直出 80 集」）当作确定性产能承诺；
- 不输出可导入的项目/工作流文件。
