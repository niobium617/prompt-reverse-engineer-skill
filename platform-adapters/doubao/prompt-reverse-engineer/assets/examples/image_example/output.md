## 五、使用提示

- `/imagine prompt:` 整行可直接粘贴到 Midjourney 使用；`--v 8.2` 已是当前默认版本
- 换风格：把风格迁移版中的「吉卜力动画风格」替换为任意目标风格词（参考 `image_rules.md` 第六节词库）
- V8 角色/服装一致性用 Edit Model（最多 4 张参考图），不要再用 V7 的 `--cref` / `--oref`
- 需要 SD 版本时追加 `--models sd` 重新编译；FLUX.2 不支持负向词，改用正向约束
