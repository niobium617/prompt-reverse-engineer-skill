## 边界

- 模型标识、模式支持、时长与分辨率档位、参考主体数量、音频参数：以 Vidu 官方文档与控制台为准。
- `[@名称]` 参考主体写法来自官方参考生视频说明；本 Skill 用顶层 `reference_note` 承载名称与用途，不自动生成 `[@名称]`，避免与结构化 `video_references` 重复。
- `1-16 秒、540p/720p/1080p、声音默认开启` 为公开资料常见值，实际档位与默认值以控制台为准。
- 「主体 + 动作 + 场景 + 镜头语言 + 光影色彩 + 氛围」的短段落结构、扁平字段契约、P0–P3、六维评分、审查清单：本 Skill 的设计建议，不是官方固定 Prompt 模板。
