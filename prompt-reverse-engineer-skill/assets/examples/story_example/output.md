## 六、使用提示

- **占位替换**：`林晓` 的外形/服装可替换为你的角色设定；`16:9` 与 `8`/`10` 秒时长按需调整。
- **风格切换**：替换各场景 `style` 段（如改「宫崎骏动画风格」）即可整体换风格；需保证全篇一致。
- **负向词**：三类结构（画面瑕疵/风格违和/内容违和）可随时追加；FLUX.2 不支持负向，需改成正向约束。
- **单图出图**：把任一场景的 MJ/SD Prompt 直接粘贴到对应工具即可，V8.2 默认即当前版本。
- **视频衔接**：相邻场景首尾动作尽量可匹配（如场景 1 结尾两人对视 → 场景 2 开场相对而坐）。
