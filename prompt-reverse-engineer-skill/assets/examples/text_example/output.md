# 示例输出：文本模式（input.md → GPT-4/Claude Prompt）

## 一、分析摘要

- **模态**：文本（本地文件）
- **脚本信号**：全文字数 ≈ 130 字；CJK 语言；感叹号 2 处；emoji 2 个；带有序列表与加粗标题；可读性档：简
- **角色定位**：消费电子领域资深种草文案策划，深谙电商爆款逻辑
- **写作风格**：口语化短句，语气亲切有网感，多用感叹号收尾；高频词：爆款、绝绝子、闭眼入
- **结构逻辑**：吸睛标题（含数字卖点）→ 痛点场景引入 → 卖点分条列述 → 限时促单结尾
- **约束规则**：全文 ≤200 字；含 2-3 个 emoji；禁用绝对化用语

```
任务：撰写一款电动牙刷的电商种草文案。
写作风格：口语化短句，语气亲切有网感，多用感叹号收尾；高频词：爆款、绝绝子、闭眼入。
结构要求：吸睛标题（含数字卖点）→ 痛点场景引入 → 卖点分条列述 → 限时促单结尾。
限制：全文不超过 200 字；含 2-3 个 emoji；禁止使用“最”“第一”等绝对化用语。
输出格式：标题一行 + 正文 3 段 + 促销信息一行。

[User]
请基于以上设定生成一篇同类内容，主题：[此处填写主题]
```
