# v3.1.0 发布说明

> 发布日期：2026-11-18
> 版本源：[`VERSION`](../VERSION) = `3.1.0`

本 Release 覆盖自 v2.1.0 以来的全部能力，包括 Muse Image / Seedance、实拍镜头反推、IR 1.0、三平台适配、ComfyUI 工作流只读解析（甲 / 乙 / 丙）与本次四模型补齐 + 离线基准（丁）。

## 本次新增（丁阶段）

### 四个新模型模板

| 模型 | 模板 | 用途 | 默认参数 |
|---|---|---|---|
| Kling 4.0（可灵） | `kling.json` | 文生视频 / 首帧 / 首尾帧 / 多图参考 / params | 10s / 1080p / 16:9 / 声音开 |
| Hailuo 3（MiniMax H3） | `hailuo.json` | 同上 | 10s / 1080P / 16:9 / 声音开 |
| Vidu Q3 | `vidu.json` | 同上 | 8s / 1080p / 16:9 / 声音开 |
| 即梦 5.0（Seedream 5.0） | `jimeng.json` | 文生图 / 复刻 / 编辑 / 参考图 / 多图融合 / params | 2K / 16:9 / 水印关 |

- 全部沿用「新模型 = 新模板」零代码路径，编译器自动注册，模型数 12 → 16。
- 每个模型附独立 `*_sources.md` 与 `last_verified: 2026-11-18`；未直接核实的档位标「待人工确认」，不写成官方保证。
- Kling / Hailuo / Vidu 提供 `shot_style`，可在 `--models` 中显式点名；默认镜头反推集合不变（视频四款、图片六款）。

### 离线基准 `benchmarks/`

- 10 例：图片 3 / 视频 3 / 工作流 2 / 平台 2。
- 每例含输入 fixture、结构层断言、`gold.md` 语义金标与 5 维评分锚点。
- 结构层由 `tools/benchmarks.py` 自动执行；语义层只打印 `[MANUAL]`，由 Agent / 人工按 `benchmarks/rubric.md` 评分，不接入自动打分。
- 支持 `--check`、`--suite image --check`、`--schema-only`、`--list`；全程离线、确定性、无 API Key。

## 自 v2.1.0 以来累计能力

- **Muse Image 1.0**：八种任务模式、十类空间关系、参考图迁移边界、Anchor / 多轮 / 文字版式。
- **Seedance 2.5**：六种任务模式、素材角色契约、首帧 / 首尾帧 / 全模态参考互斥、参数边界。
- **实拍镜头反推**：图片与视频逐镜镜头卡、12 维枚举、证据分级、逐模型独立 Prompt、镜头审查清单。
- **IR 1.0 与三注册表**：11 模块契约、`ir validate`、模型 / 平台 / 能力注册表确定性生成。
- **三平台适配**：ComfyUI（L2）/ Runway（L1）/ LibTV（L1）五件套、来源闸门、安装物化。
- **ComfyUI 工作流只读解析**：API/UI JSON 节点与连线统计、未知节点警告、跨平台兼容报告与手工重建步骤；固定 `importable_output: false`。

## 兼容性

- **无破坏性变更**：新增模型与基准均为增量；未指定模型时的默认输出仍为 Midjourney V8.2 + GPT-5.5/Claude 5.5。
- 模型别名保持兼容；`--models all` 现在输出 16 种格式。
- 注册表模型数由 12 增至 16，`gen_registry.py --check` 可逐字节复现。
- 豆包 zip 与 Codex 清单已重新生成；升级需重新安装或上传。

- 豆包：重新上传 `platform-adapters/doubao/prompt-reverse-engineer.zip`，或粘贴 `doubao_instruction.md`
- 发布检查表见 [`docs/RELEASE.md`](RELEASE.md)

## 边界

- 不调用任何模型或平台 API，不联网，不需要 API Key。
- 不执行 ComfyUI 工作流，不生成 / 导入 / 导出可导入工作流。
- 语义层基准不自动评分；结构层通过不等于「写得好」。
- 来源未直接核实的模型参数标为「待人工确认」，不冒充官方事实。
