# 统一 Prompt → LibTV 映射规则

> 平台：LibTV ｜ 核验日期：2026-11-17 ｜ 能力等级：L1
> 本文件只做创作步骤与 Prompt 映射；不调用接口、不安装插件、不授权账号、不生成项目文件。

## 1. 总原则

LibTV 的公开能力是**创作流程**（剧本 → 角色 → 分镜 → 生成 → 音频/剪辑），节点结构与字段未公开。统一 Prompt 按流程层拆分：

```
统一 Prompt
├── 剧本层 → 题材 / 一句话梗概 / 角色 / 世界观 / 核心冲突
├── 角色层 → 外形 / 服装 / 年龄 / 气质 / 跨镜一致性
├── 分镜层 → 镜号 / 景别 / 运镜 / 时长意图 / 台词
└── 逐镜生成层 → 每镜一条图片或视频 Prompt（主体、动作、场景、光影、风格）
```

先给「几步、每步交什么」，再给逐层内容与逐镜 Prompt。不要声称能填进某个具体字段——字段名官方未公开，一律标「需人工确认」。

## 2. 分层写法

### 2.1 剧本层

- 题材与场景模板：短剧 / 漫剧 / 影视 / 自媒体 / TVC 广告 / 游戏（已验证类别）；
- 一句话梗概：一句话说清主角、欲望、阻碍、结果；
- 角色设定：主要角色 + 关系 + 核心看点；
- 时代背景与目标受众；
- 原创或改编：改编须说明原作边界，不复制受版权保护的具体表达。

### 2.2 角色层

每个主要角色给固定锚点：年龄、性别、外形、发型、服装、气质、标志物。跨镜一致性按「文字锚点 + 参考图」双约束写，不承诺平台会自动锁定同一角色。

### 2.3 分镜层

每个镜头一行，至少写：镜号、景别、运镜、时长意图、画面内容、台词/旁白、转场意图。分镜字段结构官方未公开，输出为表格供人工填入。

### 2.4 逐镜生成层

每镜一条可独立粘贴的 Prompt：

- 图片：主体 + 动作 + 场景 + 光影 + 色彩 + 构图 + 风格；
- 视频：在图片 Prompt 基础上加运动描述、运镜、时长意图；
- 多镜衔接：写明「上一镜结束状态 → 本镜起始状态」。

### 2.5 音频与剪辑层

官方有音频生成与智能剪辑，但接口与参数未核验。只给意图描述（配音语气、音效点、配乐情绪、镜头顺序与节奏），具体操作标「需人工确认」。

## 3. 参数与选项

| 统一字段 | LibTV 落点 | 置信度 |
|---|---|---|
| 模型选择 | 生成界面的模型选项 | 已验证（模型存在）／可用性需人工确认 |
| 画幅 / 分辨率 / 时长 | 生成界面选项 | 需人工确认 |
| 场景模板 | 6 大场景模板 | 已验证（类别）／具体选项需人工确认 |
| 角色一致性 | 角色设定 / 资产 | 需人工确认（实现方式未公开） |
| 分镜字段 | 分镜 / 剧本界面 | 未验证 |
| 音频 / 配乐参数 | 音频生成界面 | 未验证 |
| API 参数 | 未公开 | unknown |

不得把 `assets/templates/` 中的通用模型模板参数当成 LibTV 界面字段；两者不是同一层。

## 4. 素材输入输出说明（回答必填）

| 环节 | 输入 | 输出 | 备注 |
|---|---|---|---|
| 剧本 | 创意 / 原文 / 大纲 | 剧本文本 | 可导入或原创 |
| 角色设定 | 角色描述 / 参考图 | 角色卡 | 平台内实现方式未公开 |
| 分镜 | 剧本 + 角色卡 | 镜头表 | 字段需人工确认 |
| 逐镜生成 | 每镜 Prompt + 参考素材 | 图片 / 视频片段 | 模型与选项需人工确认 |
| 音频 / 剪辑 | 片段 + 音轨意图 | 成片 | 平台原生能力，本 Skill 不调用 |

## 5. 输出模板

回答「把这份分析映射到 LibTV」时，固定给出：

1. **创作步骤映射**：剧本 → 角色 → 分镜 → 逐镜生成 → 音频/剪辑；
2. **分层内容**：剧本要点、角色卡、分镜表；
3. **逐镜 Prompt**：每镜一段，可独立粘贴；
4. **素材说明**：参考图/首帧的角色与建议接法；
5. **不兼容项**：无法确认的字段、节点、API；
6. **降级方案**：界面不可见 / 账号或插件不可用时怎么退；
7. **置信度标记**：已验证 / 未验证 / 需人工确认。

## 6. 示例（片段）

统一需求：把一段 60 秒产品短剧拆成 LibTV 创作步骤。

| 步骤 | 环节 | 输入 | 输出 | Prompt 落点 |
|---|---|---|---|---|
| 1 | 剧本 | 产品卖点、受众、时长 | 一句话梗概 + 三幕 | 剧本层 |
| 2 | 角色 | 主角设定 | 角色卡 | 角色层（文字锚点） |
| 3 | 分镜 | 剧本 + 角色卡 | 6 镜镜头表 | 分镜层 |
| 4 | 逐镜生成 | 每镜 Prompt + 产品参考图 | 6 段视频素材 | 逐镜 Prompt |
| 5 | 音频 / 剪辑 | 素材 + 配音意图 | 成片 | 平台原生；本 Skill 不调用 |

置信度：场景模板类别与模型存在属已验证；分镜字段、音频参数、角色锁定方式属需人工确认或未验证。

> 该示例是人工操作说明，不是可导入的剧本文件或工作流，也不保证在当前账号中可直接出片。
