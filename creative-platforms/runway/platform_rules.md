# Runway 平台规则（Workflows）

> 核验日期：2026-11-17 ｜ 状态：`verified` ｜ 本 Skill 能力等级：L1（Prompt）；参数级映射未核验
> 官方来源与未核验边界见 [sources.md](sources.md)。

## 1. 平台定位

Runway Workflows 是**可视化多步骤创作流水线**：把输入节点、媒体模型节点与 LLM 节点连成一条管线，发布为**一个 API 端点**，由 Runway Dev 调用。官方说明强调：

- 可组合多个模型、模态与任务，输出直接接到下一步输入；
- 无论多少步，对外只有一个端点；编辑并重新发布后，调用方使用的端点不变；
- 可保存为模板，团队复用；
- 按实际使用的模型与处理步骤计费；
- 可先在可视化界面搭建并测试，再发布为端点。

另有预置 **Recipes**（如广告本地化、产品广告、多镜头视频、产品 UGC 等），可作为起点。

## 2. 节点类别（官方已确认）

| 节点类别 | 作用 | 官方给出的输入/输出 |
|---|---|---|
| Input nodes | 工作流入口：上传媒体或输入文本 | 图片、视频、文本 |
| Media Model Nodes | 用 Runway 生成模型把输入变成新图片/视频；可在同一工作流混用模型 | 输入图片/视频/文本，输出图片/视频 |
| LLM Nodes | 分析、增强、改写 Prompt；也可分析图片生成描述 | 输入文本/图片，输出文本 |

官方产品页列出的媒体模型包括 Gen-4、Gen-4 Turbo、Flash 2.5、Veo 3.1，并注明还有其他模型；开发者页展示 Gen-4.5 节点。官方 FAQ 明确 Workflows 可组合 Runway 模型与其他实验室的精选模型。

**未确认**：各节点的具体参数名、端口顺序、默认值、UI 控件名称。不得臆造。

## 4. 本 Skill 的使用规则

### 4.1 Prompt 落点

统一 Prompt 进入 Runway Workflows 时，按**步骤**拆分：

- 文本输入节点：放创作 brief、分镜描述、角色设定；
- 媒体模型节点：放该步骤的生成 Prompt（文生图/图生视频/视频改写等）；
- LLM 节点：可选，用于扩写或统一语气；本 Skill 已产出成稿，**默认不依赖 LLM 节点二次改写**；
- 输出：图片/视频进入下一步，或作为最终产物。

回答必须按「节点顺序 + 每步输入输出」组织，而不是给一个整段 Prompt 了事。

### 4.2 参数

Runway 的节点参数没有在本次核验的官方页面中逐项公开。因此：

- 只写「在该媒体模型节点中选择模型与时长/画幅等选项」；
- 具体参数名、默认值、可选范围一律标「需人工确认」；
- 不把 Runway 模型模板（`runway.json`）里的 Prompt 格式等同于 Workflows 节点参数；
- 不承诺某个模型一定可用（模型会随账号与上线状态变化）。

### 4.3 推荐回答结构

1. **步骤映射**：输入 → 模型节点 →（可选 LLM）→ 输出，逐步说明；
2. **素材输入输出**：每个节点吃什么、吐什么、接到哪里；
3. **参数与选项**：只列已确认的类别，其余标「需人工确认」；
4. **不兼容项**：本地执行、任意自定义节点、工作流文件导入导出等；
5. **降级方案**：无法确认节点/参数时，退化为「分步 Prompt + 人工搭建说明」；
6. **置信度标记**：已验证 / 未验证 / 需人工确认。

## 5. 不兼容与降级

| 情况 | 处理 |
|---|---|
| 用户要「导入/导出 Runway 工作流文件」 | 官方未公开该格式；明确说无法提供，改为步骤说明 |
| 用户要本 Skill 直接调用 Runway API 跑生成 | 拒绝：本 Skill 不做 L4，不索取 API Key |
| 用户要精确节点参数/默认值 | 标「需人工确认」，请以账号内 Workflows 界面为准 |
| 用户要 ComfyUI 式自定义节点 | Runway Workflows 不支持；说明差异，给替代步骤 |
| 安装态读不到 `platforms/` | 只输出通用 Prompt，并说明未加载 Runway 平台资料 |

## 6. 安全边界

- 不调用 Runway API，不创建/发布端点，不读取账号数据；
- 不提供 API Key、不引导把 Key 写进 Prompt 或仓库；
- 不把营销页功能等同于已开放给当前账号的能力；
- 不承诺生成结果、价格或排队时间。
