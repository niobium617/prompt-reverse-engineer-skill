# 统一 Prompt → Runway Workflows 映射规则

> 平台：Runway Workflows ｜ 核验日期：2026-11-17 ｜ 能力等级：L1
> 本文件只做 Prompt 与步骤映射；不调用 API、不发布端点、不生成工作流文件。

## 1. 总原则

Runway Workflows 的最小单位是**节点**，不是「一条 Prompt」。统一 Prompt 要按流水线阶段拆分：

```
统一 Prompt
├── 创作 brief / 角色设定 / 分镜文字 → 文本输入节点（或 LLM 节点输入）
├── 每一步的画面 Prompt → 对应媒体模型节点
├── 参考图 / 首帧 / 尾帧 / 视频素材 → 图片或视频输入节点
└── 输出 → 下一节点输入，或最终产物
```

必须先说明「几步、每步做什么」，再给每步 Prompt。不要把整段长 Prompt 直接塞给一个模型节点了事。

## 2. 分步写法

### 2.1 文本输入节点

写清楚：

- 创作目标（广告 / 短片 / 产品图 / 多镜头叙事）；
- 受众与平台（竖屏/横屏、时长、语言）；
- 角色/产品/场景的固定设定；
- 禁止项（品牌元素、人物特征、文字错误等）。

文本输入节点是「全局 brief」，不承担具体画面生成。

### 2.2 媒体模型节点

每个生成步骤一条 Prompt，只描述该步骤的画面：

- 单张图 / 单镜头：主体、动作、场景、光影、色彩、镜头、风格；
- 图生视频：首帧内容 + 运动描述 + 运镜 + 时长意图；
- 多镜头：每镜头一份 Prompt，并在步骤说明中给顺序与衔接；
- 参考图：写明「参考什么、保留什么、禁止迁移什么」，并接到对应输入节点。

Prompt 语言按目标模型习惯写自然语言；不要在 Prompt 里写节点参数。

### 2.3 LLM 节点（可选）

官方 LLM 节点可扩写/分析 Prompt。本 Skill 的默认策略：

- 已有成稿时**不依赖** LLM 节点二次改写，避免偏离逆向结论；
- 若用户明确要用 LLM 节点统一语气，给它一段「改写约束」，而不是让它自由发挥；
- 回答中注明「该步骤可选，关闭后不影响主流程」。

## 3. 参数与选项

本次核验的官方页面没有逐项公开节点参数名与默认值，因此统一按「需人工确认」处理：

| 统一字段 | Runway 落点 | 置信度 |
|---|---|---|
| 画幅 / 时长 | 媒体模型节点的输出选项 | 需人工确认 |
| 模型选择 | 媒体模型节点下拉项 | 已验证（模型类别）／具体可用性需人工确认 |
| 首帧 / 尾帧 | 图片输入节点接到图生视频节点 | 需人工确认（端口名） |
| 参考图 / 风格图 | 图片输入节点 + 模型节点 | 需人工确认 |
| 种子 / 采样参数 | 官方页面未公开 | unknown |
| 音频 / 配乐 | 官方 Workflows 页面未展开 | unknown |

不得把 Runway 模型模板（`assets/templates/runway.json`）里的参数当成 Workflows 节点参数；两者不是同一层。

## 4. 素材输入输出说明（回答必填）

对每个节点写清：

| 节点 | 输入 | 输出 | 备注 |
|---|---|---|---|
| 文本输入 | 用户文本 | 文本 | 全局 brief |
| 图片/视频输入 | 本地素材 | 图片/视频 | 素材角色需写明 |
| 媒体模型 | 文本 + 可选图片/视频 | 图片/视频 | 模型与选项需人工确认 |
| LLM（可选） | 文本/图片 | 文本 | 不默认启用 |
| 端点 | 调用参数 | 最终产物 | 平台原生能力，本 Skill 不调用 |

## 5. 输出模板

回答「把这份分析映射到 Runway 工作流」时，固定给出：

1. **映射结果**：步骤表（步骤号 / 节点类别 / 输入 / 输出 / Prompt 落点）；
2. **逐步 Prompt**：每步一段，标明对应节点；
3. **素材说明**：每张图/每段视频的角色与接法；
4. **不兼容项**：无法映射的步骤与原因；
5. **降级方案**：参数未知、模型不可用、账号不可用时怎么退；
6. **置信度标记**：已验证 / 未验证 / 需人工确认。

## 6. 示例（片段）

统一需求：把一段 15 秒产品广告拆成 Runway 工作流。

| 步骤 | 节点类别 | 输入 | 输出 | Prompt 落点 |
|---|---|---|---|---|
| 1 | 文本输入 | 产品 brief、受众、卖点 | 文本 | 全局设定与禁止项 |
| 2 | 媒体模型（图） | 步骤 1 文本 + 产品参考图 | 产品主视觉 | 产品图 Prompt |
| 3 | 媒体模型（视频） | 步骤 2 图片 | 3 秒产品特写 | 图生视频 Prompt（运动/运镜） |
| 4 | 媒体模型（视频） | 步骤 1 文本 | 3 秒使用场景 | 文生视频 Prompt |
| 5 | 端点输出 | 步骤 3+4 | 成片素材 | 平台原生；本 Skill 不调用 |

置信度：节点类别与单端点属已验证；模型参数、端口名、时长选项属需人工确认；计费与排队时间不作承诺。

> 该示例是人工搭建说明，不是可导入的工作流，也不保证在当前账号中可直接发布。
